# Gym Assister (Cloud Deployment)

An AI-powered personal trainer, workout planner, and diet tracking web application built with **Streamlit**, **LangChain**, and **Upstash Redis** cloud storage.

---

### Original Repository
The original project is hosted [here](https://github.com/VenomxSpiderman/gym-assistant.git).


---

### Key Features
- **AI Personal Trainer**: Chat interface to discuss fitness goals, receive custom advice, and generate structured workout & diet plans.
- **Cloud Persistence**: User authentication and workout profiles are synchronized with Upstash Redis.
- **Progress Tracking & Analytics**: Interactive weekly logging, workout adherence metrics, caloric calculations, and visual progress charts.
